## ✅ 학습 원칙

1. 문제를 충분히 고민한 뒤 코드를 작성합니다.
2. 정답 여부뿐 아니라 시간·공간 복잡도를 확인합니다.
3. 틀린 문제는 원인을 기록하고 다시 풀이합니다.
4. 더 간결하고 효율적인 풀이가 있는지 비교합니다.

## 📝 풀이 기록

각 문제는 다음 내용을 중심으로 정리합니다.

- 문제 해결 아이디어
- 사용한 알고리즘과 자료구조
- 정답 코드
- 시간·공간 복잡도
- 오답 원인과 개선점
